
## Pneumonia Detection from Chest X-Ray Images using Deep Learning

## 📌 Project Overview

This project builds a Deep Learning model using Convolutional Neural Networks (CNN) to detect Pneumonia from Chest X-ray images.

The model classifies X-ray images into two categories:

Normal

Pneumonia

Early detection of pneumonia can help doctors provide faster treatment and reduce health risks.

## 🎯 Business Problem

INX Future Inc. has observed a decline in employee performance, which is impacting overall productivity and client satisfaction.

Management wants to identify:

The factors affecting employee performance

Departments with high and low performance

Key attributes influencing performance ratings

Using data analysis and machine learning, this project helps predict employee performance and provides insights for decision-making.

## 🎯 Project Objectives

Department-wise Performance Analysis

Analyze employee performance across different departments.

Identify Key Performance Factors

Find variables affecting employee ratings.

Build a Machine Learning Model

Train a predictive model to classify employee performance.

Predict Future Performance

Use the trained model to predict employee performance for new data.
